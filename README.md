# Torre de Hanói 3D - Simulação com K-Pinos

Simulação 3D interativa do clássico problema da Torre de Hanói, generalizada para múltiplos pinos utilizando uma variação do **Algoritmo de Frame-Stewart**. 

Desenvolvido como projeto acadêmico para o curso de Engenharia da **Universidade Federal do Rio de Janeiro (UFRJ)**.

## 🚀 Funcionalidades
* **Renderização 3D:** Visualização completa e adaptativa usando `VPython`.
* **Generalização Matemática:** Resolve para o caso clássico (3 pinos) e otimiza a divisão de discos para *K* pinos.
* **Câmera Livre (Flycam):** Navegação pelo espaço 3D utilizando as teclas `W A S D` e centralização com a tecla `C`.
* **Controle Dinâmico:** Ajuste da velocidade de animação em tempo real via interface gráfica (slider).
